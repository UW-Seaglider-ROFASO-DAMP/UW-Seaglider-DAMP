# UW Seaglider Damage Assessment Protocol System

This is the github for the University of Washington Seaglider Damage Assessment Protocol (D.A.P.) System, a 2026 Aeronautical & Astronautical Capstone!

# Overview

This D.A.P. system was created to create a diagnosis on the Seaglider's condition during its mission for the Student Seaglider Center at UW.

Most of the code in this github was created in MATLAB, as such MATLAB software is required to run the D.A.P. system. 

The main code files for the D.A.P. system is under the Seaglider_DAP_System folder, all the files inside the folder will need to be downloaded onto your computer.  

You also will need to have the .log and .nc files transmitted from the Seaglider on your computer to run the code. 

The main script that will be used is DAP_Main_Full_System_Test.m, which utilizes functions of the other code files to run together.  

Running this code will allow the user to run a diagnosis on the Seaglider's condition depending on the dive data submitted from the four following conditions as of June 4th, 2026:
- Nominal
- 25% Wing
- 50% Wing
- 50% Rudder
